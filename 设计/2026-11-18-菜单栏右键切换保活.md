# 菜单栏右键切换保活（2026-11-18，用户需求）

## 需求

菜单栏图标：**左键单击保持原样＝打开菜单**；**右键单击＝直接切换保活（开/停）**，作为隐藏快捷键，不进菜单。

用户原话要点：「左键还是打开菜单，但是就一个隐藏小功能，右键可以直接切换，这样子方便我需要的时候就快速切换。」（2026-11-18）

## 关键约束与选型

SwiftUI `MenuBarExtra`（`.menu` 风格）把左键和右键都接到「开菜单」，没有挂右键行为的入口——想在保留原生菜单外观的同时分流右键，只能自己持有 `NSStatusItem`。

**选型：菜单栏壳从 SwiftUI App/MenuBarExtra 改为 AppKit `NSStatusItem` + `NSMenu`**，菜单内容按原 SwiftUI 菜单逐项复刻（状态段/保活开关/开机自启/登录项待批准/系统级防睡/退出/版本号），每次打开现算快照。

被否决备选：① 通过 KVC 抓 MenuBarExtra 内部的 NSStatusItem 改 action——私有结构，系统升级即碎；② 全局右键监听 + 读完图标位置再关菜单——会先弹菜单再关，闪烁且依赖 AX 坐标。

## 行为规格

- **左键单击**：弹菜单（同原菜单；打开时刷新 pmset 读数与登录项状态）。
- **右键单击**：切换保活。保活中→停止；未保活/启动失败→开启；**启动中→取消这次启动**（不叠第二次 start）。
- 两条路径共用 `setKeepAlive`：写 `resumeKeepAliveOnLaunch`，与原菜单按钮语义一致（退出后下次启动自动恢复保活）。
- **图标沿用原语义**：保活中 `bolt.circle.fill`，未保活 `zzz`（template 图，深浅菜单栏自适应）。右键切换后立即换图标。
- **右键不进菜单**：菜单项仍是「开启保活 / 停止保活」，右键只在图标上生效（隐藏快捷键，不占菜单版面）。
- 实现要点：不常设 `statusItem.menu`（常设会把右键也变成开菜单）；`button.sendAction(on: [.leftMouseUp, .rightMouseUp])` + `NSApp.currentEvent` 分左右；左键分支临时挂 menu → `performClick` → 摘掉。

## 代价与边界

- SwiftUI 菜单换成 NSMenu，小字行改用 `NSFont.smallSystemFontSize` 的 attributedTitle 复刻 caption 观感；菜单项行为逐条对齐原实现（含「登录项待批准」「等待管理员确认…」条件项）。
- 菜单是打开时的快照（原 SwiftUI 菜单在打开期间可被 @Published 刷新）——本应用所有菜单动作都会关闭菜单，无实质差别。
- 版本号未动（仍 0.3.3）：本次改动只在 shell，引擎源码未改；发版时按 HANDOFF 三处同步 bump 到 0.3.4，并同步 dsh-clamawake 插件内引擎。

## 实机验证（2026-11-18，本机）

- 左键点击 → 菜单正常弹出：当前状态：未保活 / 保活档位 1800×1169 HiDPI / 开启保活 / 开机自启 ✓ / 系统级防睡 ✓ / 退出 / v0.3.3。
- 右键点击 → `vd-engine list` 出现 `kya=yes mirror_of=1` 虚拟屏（id=99），caffeinate 与 vd-engine 进程在，图标变实心闪电。
- 再右键 → 虚拟屏消失、vd-engine 进程退出、`resumeKeepAliveOnLaunch` 落 0。
